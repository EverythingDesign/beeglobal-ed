# BeeGlobal Webflow code

This repository contains custom JavaScript for the BeeGlobal Webflow site.

## Requirements

- Node.js 18 or newer
- npm
- `lsof` (included with macOS and most Unix-like development environments)

## Project structure

- `codes/` contains editable source files, grouped by page or feature.
- `dist/` contains minified browser bundles generated by esbuild.
- `build.js` recursively discovers JavaScript entry points under `codes/` and preserves their folder structure in `dist/`.
- `localhost.pem` and `localhost-key.pem` secure the local proxy used by an HTTPS Webflow page.

## Local development

Install dependencies and start the local servers:

```bash
npm install
npm run dev
```

`npm run dev` creates a self-signed localhost certificate and key on first use.
`codes/common/utils.js` is still a starter placeholder. The hero script opens
the Legend panel from its heading and closes it when the open panel is clicked.
Paste `codes/hero/hero-side-panel.css` into the Home page's Webflow custom CSS;
the JavaScript only changes the panel's open class.

Source files are served from `https://localhost:3001/`. On first use, visit
<https://localhost:3001/common/utils.js> and accept the browser warning for the
self-signed development certificate.

Add local scripts to Webflow's **Before `</body>` tag** field:

```html
<script src="https://localhost:3001/common/utils.js"></script>
<script src="https://localhost:3001/hero/hero-animations.js"></script>
```

Load shared utilities before page-specific files, then reload the Webflow preview
after saving a local change.

## Production build

Build every JavaScript file under `codes/` into a minified file at the matching
path under `dist/`:

```bash
npm run build
```

To rebuild automatically while editing:

```bash
npm run watch
```

After deploying `dist/` to a CDN, replace local Webflow URLs with production URLs,
for example:

```html
<script src="https://cdn.jsdelivr.net/gh/armoredcat/beeglobal-repo@latest/dist/common/utils.js"></script>
<script src="https://cdn.jsdelivr.net/gh/armoredcat/beeglobal-repo@latest/dist/hero/hero-animations.js"></script>
```

Then publish the Webflow site.
